## 🌸 About the Project

This is my personal portfolio website, created as part of my Web Development Assignment at Gauteng City College, Faculty of Information Technology.

The purpose of the website is to introduce myself, showcase my technical skills and projects, highlight my education, and provide a way for visitors to contact me.

The website was designed and developed from scratch using HTML5, CSS3 and JavaScript, with a focus on responsive design, accessibility, usability and a personal lavender-themed visual identity.

## 🎨 Design

The website uses a lavender, black and white colour palette to create a clean and personal visual identity.

The design focuses on:

- Simplicity
- Readability
- Responsive layouts
- Clear navigation
- Consistent spacing
- Personal branding
- Accessibility
- User interaction

The website was designed specifically for this portfolio project rather than using an unedited template.
